# Contributing

Pull requests and focused commit proposals are welcome.

## Before submitting

- Base the change on the current `main` branch and keep unrelated changes out of the same pull request.
- Describe the behavior changed, the kernels or Android versions affected, and how the change was verified.
- Preserve existing SPDX, copyright, license, and provenance notices.
- Identify every third-party source used by the change and confirm that its license is compatible with `GPL-2.0-only`.
- Do not submit code that you do not have the right to contribute.
